# פרויקט שבעים פנים לתורה (Seventy Faces)

תיקייה זו נוצרה על מנת לשלב את פרויקט "שבעים פנים".

**הוראות למשתמש:**
1. אנא חלץ את תוכן ה-ZIP של הפרויקט שהורדת.
2. העלה את כל הקבצים שלו (או לפחות את התיקיות והקוד שלו) לתוך תיקייה זו (`src/seventy-faces`).
3. לאחר מכן נוכל לעדכן את נקודות הממשק ב-`App.tsx` כך שיטעינו את הרכיב הראשי של שבעים פנים (למשל `src/seventy-faces/App.tsx`).

עד שתעלה את הקבצים, הממשק יציג הודעה המבקשת ממך לעשות זאת.
