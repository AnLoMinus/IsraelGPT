# בונה אפליקציות לאנדרואיד (APK Builder) - גרסה מקצועית

תיקייה זו מכילה כלים להמרת הפרויקט (React/Vite) לאפליקציית אנדרואיד (APK) חכמה, מקצועית ומותאמת במלואה למכשירים ניידים.
התהליך מבוסס על **Capacitor**, וכולל אוטומטית שילוב מנגנוני מובייל מקצועיים:

- **Viewport Safe-Area:** תמיכה במגרעות מסך (Notch) ואזורים בטוחים.
- **מסך פתיחה חכם (Splash Screen):** מסך רקע כהה מקצועי למניעת הבהובים בעת פתיחת האפליקציה.
- **שורת סטטוס משולבת (Status Bar):** התאמת שורת ההתראות לצבעי האפליקציה.
- **מקלדת דינמית (Keyboard):** התאמת מידות העמוד למקלדת קופצת כך שתיבות טקסט לא יוסתרו.

## דרישות קדם (להרצה על המחשב המקומי שלך)

כדי שהסקריפט יעבוד בצורה תקינה לאחר הורדת הפרויקט למחשב שלך, עליך לוודא שמותקנים אצלך הדברים הבאים:

1. **Node.js ו-npm**: להרצת פקודות הבנייה.
2. **Java Development Kit (JDK)**: גרסה 17 מומלצת.
3. **Android Studio**: התקן את Android Studio וודא שמותקן לך Android SDK מתוך המערכת.
4. **משתני סביבה**: ודא שמשתני הסביבה `JAVA_HOME` ו-`ANDROID_HOME` מוגדרים במערכת שלך.

## יצירת אייקונים (אופציונלי אבל מומלץ)
כדי לייצר אוטומטית אייקון לאפליקציה בטלפון ומסכי פתיחה, צור תיקייה בשם `assets` בתיקייה הראשית של הפרויקט.
שים שם תמונה ריבועית בשם `icon.png` (רזולוציה לפחות 1024x1024) ותמונה נוספת בשם `splash.png` (רזולוציה 2732x2732) - הסקריפט שלנו ידאג לייצר מזה את כל הגדלים לטלפון!

## איך להשתמש?

1. הורד את כל הפרויקט מקוד המקור למחשב שלך (כקובץ ZIP).
2. חלץ את התיקייה.
3. פתח מסוף (Terminal / Command Prompt) בתיקייה של הפרויקט.
4. הרץ את הפקודה להתקנת מודולים ראשונית:
   ```bash
   npm install
   ```
5. היכנס לתיקיית הקומפיילר:
   ```bash
   cd apk-builder
   ```
6. תן הרשאות הרצה לסקריפט (במערכות מבוססות לינוקס/מאק):
   ```bash
   chmod +x build-apk.sh
   ```
7. הרץ את הסקריפט:
   ```bash
   ./build-apk.sh
   ```
   *בחלונות (Windows) עליך להריץ סקריפט זה ב-Git Bash או WSL.*

## התקנה על הטלפון

לאחר שקובץ ה-`IsraelGPT-Mobile.apk` ייווצר בתיקייה הראשית, תוכל:
1. להעביר אותו למכשיר האנדרואיד שלך (דרך כבל USB, טלגרם, וואטסאפ וכו').
2. לפתוח את הקובץ במכשיר.
3. לאשר התקנה ממקורות לא מוכרים (אם המכשיר יבקש).
4. ליהנות מאפליקציית המובייל שלך!
